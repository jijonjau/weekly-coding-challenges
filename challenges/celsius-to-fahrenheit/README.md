# Celsius to Fahrenheit

## Problem

Read a temperature in Celsius and convert it to Fahrenheit.

The conversion formula is:

```text
F = C × 9/5 + 32
```

For example:

```text
Input: 25
Output: 25 Celsius = 77.0 Fahrenheit
```

## Approach

1. Read the Celsius temperature from the user.
2. Apply the Celsius-to-Fahrenheit conversion formula.
3. Print the Celsius and converted Fahrenheit values.

## Key Concepts

* User input
* Type conversion
* Arithmetic operations
* f-strings

## Run

From this folder:

```bash
python main.py
```

If that doesn't work:

```bash
python3 main.py
```
